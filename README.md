# Dana's Bakery – LangGraph Order Processing

AI Agents course assignment implementing a deterministic bakery order-processing workflow using Python and LangGraph StateGraph.

## Features
- Order input validation
- Product inventory checks
- Up to two substitution attempts
- Conditional discounts
- Delivery and pickup handling
- Final customer response
- Graph visualization and automated tests

## Files
- `dana_bakery.ipynb` – Python notebook with implementation, graph and tests
- `prompt.md` – Technical specification and Codex prompt
- `README.md` – Project documentation

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Select File > Open notebook > GitHub.
3. Enter https://github.com/adimiler111/dana-bakery-langgraph
4. Open `dana_bakery.ipynb`.
5. Select Runtime > Run all.
